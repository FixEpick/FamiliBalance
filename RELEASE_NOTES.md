# История обновлений FamiliBalance

Новые версии — сверху. При каждом релизе добавляйте секцию `## vX.Y.Z` в начало файла.

---

## v2.1.1

### 🌍 Локализация
- **Диалоги на русском** — все модальные окна родительского интерфейса (ПИН-коды, бонус-квест, сбросы, выход, удаление аккаунта, редакторы заданий и достижений, обновление приложения) теперь соблюдают язык интерфейса и не отображаются на английском

### 🎨 Улучшения UI
- **«Очистка и сбросы»** — вместо десятка кнопок «Сбросить/Очистить» теперь выпадающий список выбора + одна кнопка «Выполнить сброс» с подтверждением — меньше шанс случайного нажатия
- **Периодичность квеста** — при редактировании встроенных квестов (шкаф/комната/дневник) доступна опция «Разовое» наравне с «Ежедневно/Еженедельно»

### 🧹 Техническое
- **AGP 9.5.2** — обновлён Android Gradle Plugin
- **Чистка warnings** — устранены все предупреждения компилятора: deprecation в security-crypto/FCM/PackageManager, лишние safe-call и redundant-конверсии

## v2.1.0

### 🆕 Новое
- **Baseline Profile (AOT)** — профиль запуска встроен в APK: быстрее старт и меньше подтормаживаний в детском и родительском разделах. Модуль `baselineprofile` + сценарий `BenchmarkSession` для генерации профиля
- **Частичная выдача наличных** — в диалоге «Выдать наличные» можно ввести любую сумму (не только весь баланс), кнопка «Макс» подставляет максимум; в истории пишется точная сумма
- **Редактирование кастомных квестов** — при правке можно менять частоту (разово/ежедневно/еженедельно) и требование фото
- **Фильтр «Ручные операции» в истории** — ручные начисления/списания родителя больше не смешиваются с квестами и штрафами; добавлены разделители дат «Сегодня»/«Вчера»/дата
- **Выбор языка в настройках родителя** — строка «Язык интерфейса» в кабинете родителя
- **Подтверждение выхода** — диалог «Выйти из аккаунта?» вместо мгновенного выхода

### 🐛 Исправления
- **Выход из приложения** — убран `killProcess` при выходе: система больше не считает закрытие аварийным (WIN DEATH), состояние сохраняется корректно
- **Диалоги под статус-баром** — `windowOptOutEdgeToEdgeEnforcement` для окон диалогов на Android 15+, поп-апы не уезжают под вырез
- **Иконки статус-бара** — светлые иконки на тёмном фоне (`SystemBarStyle.dark`)
- **Ошибки входа** — локализованные сообщения вместо сырых ошибок SDK: неверный пароль, неподтверждённая почта, лимит попыток, нет сети; поля email/пароль подсвечиваются красным при invalid credentials
- **Синхронизация** — эхо собственного push'а в логе теперь debug вместо warning; добавлены тесты `SyncStatus`/`ProfileSync`

### 🎨 Улучшения UI
- **Быстрые действия родителя** — переключатель «Начислить/Списать» в виде капсулы, чекбокс штрафа упрощён
- **Темы** — смягчены цвета CYBER_PINK, INFERNO_RED, GALAXY_PURPLE
- **Верхняя панель админки** — полупрозрачный фон, убрана кнопка выбора языка (переехала в настройки)
- **Пустое состояние цели-мечты** — подсказка, как задать цель
- **Debug-сборка** — Toast с номером сборки при запуске

## v2.0.3

### 🔥 Критическое исправление
- **Падение при запуске** — исправлен `IllegalAccessError` в R8-сборке: kotlin-stdlib классы (`StringsKt__*`) больше не перепаковываются, приложение открывается стабильно

### 🆕 Новое
- **Вход под ребёнком из админки** — кнопка «🕹️ Войти как ребёнок» в панели родителя открывает детский интерфейс без PIN и без выхода из аккаунта; возврат в админку — кнопкой 👑 или системной «Назад»
- **Автосинхронизация** — при открытии вкладки «Проверка» данные обновляются сразу, без pull-to-refresh

### 🧹 Улучшения UI
- **Убран чекбокс «Запомнить меня»** со страницы входа родителя
- **Убрана кнопка «Сменить»** из верхней панели админки

## v2.0.2

### 🔒 Безопасность
- **ANDROID_ID убран** — идентификатор устройства заменён на случайный UUID: Google Play не считает его device identifier, риск отклонения снижен
- **Проверка разрешения уведомлений** — пуши больше не вызывают SecurityException на Android 13+ без POST_NOTIFICATIONS
- **Подпись обновлений** — проверка сертификата APK перед установкой сохранена и проверена в R8-сборке

### 🐛 Исправления
- **Камера и локализация** — строки камеры переведены через stringResource, Toast'ы используют applicationContext (корректная работа при смене языка)
- **Онбординг** — прогресс-бар и пейджер больше не пересобирают весь экран на каждый кадр скролла
- **Установка обновлений** — корректный fallback для Android < 8.0 при открытии настроек разрешений
- **Пуш-уведомления** — иконка уведомления вынесена в отдельный ресурс (устранён конфликт ресурсов)

### ⚙️ Техническое
- **Все lint-предупреждения устранены** — 0 ошибок, 2 осознанных предупреждения (predictive back, compose-bom)
- **Зависимости обновлены** — Kotlin 2.4.21, Supabase 3.9.0, OkHttp 5.5.1, Firebase BOM 35.2.0, CameraX 1.7.0, Media3 1.11.1, kotlinx-serialization 1.13.0 и др.
- **Версионирование зависимостей** — все версии перенесены в version catalog (libs.versions.toml)
- **21 неиспользуемая строка** удалена из ресурсов (RU + EN)
- **AAB** — отключены языковые сплиты, динамическое переключение языка работает корректно
