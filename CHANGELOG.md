# Changelog

## [1.9.5] — 2026-11-19

### ✨ Новое
- **Сброс пароля внутри приложения**: deep link `familibalance://auth` → экран «Новый пароль» → `updateUser`. Подтверждение отправки письма с email, cooldown 30 минут с обратным отсчётом на экране входа.
- **GameIcon** — единый компонент иконок для кнопок и полей.

### 🐛 Исправления
- **Навигация «Назад»**: на экране выбора роли онбординга — диалог выхода; на слайдах — шаг назад по страницам, на первом слайде — возврат к выбору роли (без закрытия приложения).
- **Сброс пароля**: кнопка «Сохранить» активна только при recovery-сессии с email — анонимная сессия `ensureSession()` больше не перехватывает `updateUser`; error-фрагменты ссылок обрабатываются без падения.

### 🎨 Полировка UI
- Онбординг: нейтральное «Укажите свою роль…», неоновое свечение кнопок ролей, формальное «вы» в слайдах родителя, опечатка «фотоотчёт».
- Auth: единый термин «Никнейм» на вкладках входа/регистрации (RU+EN), карточка-контейнер у формы регистрации игрока.

### ⚠️ Требует настройки
- **Supabase Dashboard** → Authentication → URL Configuration → Redirect URLs: добавить `familibalance://auth`, иначе письма сброса пароля не будут открывать приложение.

## [1.9.0] — 2026-11-18

### ✨ Новое
- **Онбординг для новых пользователей**: 8 страниц HorizontalPager с описанием возможностей (квесты, монеты, достижения, дневник, награды, экранное время) и выбором роли — родитель или ребёнок. Показывается один раз, флаг `onboarding_done` хранится в `app_prefs`; существующие пользователи с активной сессией проходят его автоматически.

### 🌍 Локализация
- **EN-локаль доведена до конца**: заголовки истории (`HistoryData.type` + `localizedHistoryTitle()`), строки ошибок ViewModel переведены на `UiText` (Admin/Auth), fallback для legacy-записей истории.

### 🐛 Исправления
- **OCR дневника**: результат сканирования применяется только к тому ребёнку, для которого выполнялось сканирование (`LaunchedEffect(scanState, childId)` + проверка `success.childId`).
- Удалён неиспользуемый код `createAchievement()` из `AchievementsAdminScreen`.
- Удалён запрос `POST_NOTIFICATIONS` и rationale-диалог — push-уведомления в приложении не реализованы, разрешение не требовалось.

## [1.8.1] — 2026-11-18

### 🐛 Hotfix
- **Критические падения на экранах админа**: пустой список детей больше не вызывает `NoSuchElementException` — все обращения к `children` используют `firstOrNull()` с UI-плейсхолдером.
- **Падение при запуске обновления**: `startActivity` в `UpdateDialog` вызывается с `FLAG_ACTIVITY_NEW_TASK` — работает из любого контекста (application context), установщик APK и настройки разрешений открываются без `AndroidRuntimeException`.

## [1.8.0] — 2026-11-18

### ✨ Новое
- **Встроенная камера (CameraX)** для отправки фотоотчётов — приложение больше не уходит в системную камеру, поэтому ОС не убивает процесс и не происходит рестарта на главном экране. Переключение фронтальной/основной камеры, даунскейл фото до 1080px.

### 🌍 Локализация
- **Полная поддержка английского языка (EN)**: история операций с типизированными заголовками, фильтры истории, экраны ачивок, настройки, Toast-сообщения ViewModel через `UiText`, plurals для корректных форм («1 minute / 2 minutes», «ждёт / ждут»).
- Локализованный fallback имени ребёнка (`default_child_name`) — data-слой больше не содержит захардкоженных строк.

### 🐛 Исправления
- **Критический баг «битых фото»**: при сбое загрузки в Supabase Storage push теперь прерывается до upsert — в облако никогда не попадают локальные `content://`/`file://` URI. Профиль остаётся dirty и досылается при восстановлении сети.
- **Дублирование записей в истории и балансе**: approve бонус-/кастом-квестов больше не пишет `+reward` в историю до фактического начисления — история и баланс обновляются синхронно при «Забрать награду».
- **Очистка памяти**: локальные файлы фото удаляются после успешной загрузки в Storage и при approve/reject/удалении квеста — `filesDir` не забивается.
- Локализованы ошибки сканирования дневника и прочие системные сообщения.

### ♻️ Рефакторинг
- ViewModel разделён на изолированные action-модули (`viewmodel/actions/*`).
- Легаси-экраны админки перенесены в `feature/admin`, компоненты камеры — в `feature/child/components`.
- Удалён мёртвый код: неиспользуемые ресурсы (15 шт.), поле `name` из `AppThemePalette`, захардкоженная русская строка в `ChildProfile.fromDto`.
